# Image Assets Directory

Place your custom website images in this folder (`public/images/`).

### Suggested Filenames:
- `hero-bg.png` - Home Hero Background Image
- `blessed-kit.png` - Blessed Kit Product Main Image
- `yatra-kit.png` - Yatra Kit Product Main Image
- `lakshmi-kit.png` - Lakshmi Samagri Image
- `shiva-kit.png` - Shiva Samagri Image
- `ganesh-kit.png` - Vinayaka Samagri Image
- `vishnu-kit.png` - Vishnu Samagri Image
- `kashi-silhouette.jpg` - Kashi Shiva Silhouette
- `hands-pooja.png` - Hands arranging pooja essentials
- `inside-blessed-kit.png` - Contents of Blessed Kit

The website is configured via `lib/images.js` to automatically reference local images stored here while falling back gracefully to remote images if local files are absent.
